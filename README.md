# Orita Fine Dining

Orita Fine Dining is a restaurant website concept with dedicated pages for the restaurant story, menu, and reservations.

## Features

- Restaurant homepage
- Menu page
- About page
- Reservations page
- Shared navigation, loading screen, and scroll-to-top behavior

## Stack

- React 19
- Vite
- React Router
- Tailwind CSS 4
- Motion

## Run locally

Requirements: Node.js and npm.

```bash
npm install
npm run dev
```

Build and lint:

```bash
npm run build
npm run lint
```

## Project status

This repository currently documents the frontend website. A reservations page is present, but this README does not claim that bookings are connected to a backend or persisted. Deployment and responsive behavior should be checked before using it as a portfolio case study.
